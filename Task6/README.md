## 1. Тапсырманың мақсаты

Берілген мәтіндегі сөздердің санын есептейтін бағдарлама құру.

Сөздер бір немесе бірнеше бос орын арқылы бөлінеді. Мәтіннің басында және соңында бос орындар болуы мүмкін.

## 2. Бағдарламаның жұмыс алгоритмі

1. Пайдаланушыдан мәтін енгізу сұралады.
2. Егер мәтін бос болса, бағдарлама қайта енгізуді сұрайды.
3. `CountWords()` әдісі шақырылады.
4. Мәтіндегі символдар біртіндеп тексеріледі.
5. Жаңа сөз басталған кезде санауыш 1-ге артады.
6. Сөздердің жалпы саны экранға шығарылады.

## 3. Кодты түсіндіру

### text[i] дегеніміз не және оның типі қандай?

`text[i]` — мәтіндегі индексі `i` болатын символ.

Оның типі — `char`.

Мысалы, `text = "Hello"` болса:
- `text[0]` — H
- `text[1]` — e
- `text[2]` — l

### C# тіліндегі string өзгермейтін тип пе?

Иә, `string` — өзгермейтін (immutable) тип.

Яғни құрылған мәтінді тікелей өзгертуге болмайды. Мәтінді өзгерту қажет болса, жаңа string объектісі құрылады.

### Сөздің басталғанын қалай анықтаймыз?

Бағдарламада `insideWord` логикалық айнымалысы қолданылады.

- Егер символ бос орын болмаса және `insideWord == false` болса, жаңа сөз басталды деп есептеледі.
- Санауыш 1-ге артады.
- `insideWord = true` болады.
- Егер бос орын кездессе, `insideWord = false` болады.

Осы алгоритм мәтіннің басындағы және соңындағы бос орындарды дұрыс өңдейді.

### result += ch командасы қалай жұмыс істейді?

`result += ch` командасы `result = result + ch` дегенді білдіреді.

Бұл операция жаңа string объектісін құрады, себебі string типі өзгермейді.

## 4. Бағдарламаның нәтижесі

Бұл мәселе `insideWord` логикалық айнымалысын қолдану арқылы шешілді.
